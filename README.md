## 🎯 3つの使い方

### **1️⃣ PC で使用（最初のセットアップに最適）**

#### セットアップ
```bash
cd /workspaces/anki-system
python3 -m http.server 8000
```

ブラウザで開く：
- http://localhost:8000

#### メリット
- ✅ 大きな画面で入力しやすい
- ✅ CSVファイルからのインポートが簡単
- ✅ データの大量管理が効率的

---

### **2️⃣ スマホだけで使用（移動中の学習に最適）**

#### セットアップ

**iOS（iPhone/iPad）**
1. Safari で http://localhost:8000 または https://your-server-url にアクセス
2. 「共有」→ 「ホーム画面に追加」
3. ホーム画面のアイコンから起動

**Android**
1. Chrome で http://localhost:8000 または https://your-server-url にアクセス
2. ブラウザメニュー → 「アプリをインストール」
3. ホーム画面のアイコンから起動

#### メリット
- ✅ いつでもどこでも学習できる
- ✅ インターネット不要（オフライン対応）
- ✅ アプリのようにサクサク動作
- ✅ すべてのデータはスマホ内に保存

---

### **3️⃣ PC + スマホの連携（最も効率的）**

```
┌─────────────────────────────────────────────────┐
```

## 🌐 オンラインサーバーへのデプロイ（オプション）

## 🔐 セキュリティと プライバシー

このアプリは以下の特徴があります：

- ✅ **ローカルストレージ** - すべてのデータがスマホ内に保存
- ✅ **オフライン対応** - インターネット不要
- ✅ **クラウド連携なし** - 第三者にデータが見えない
- ✅ **Service Worker** - キャッシュ対応でオフラインでも動作

**プライバシーリスク：ほぼゼロ** ✨

## 📞 トラブルシューティング

### 質問1：「Service Worker が登録されません」
**回答：** 
- HTTPS または localhost でのみ動作します
- オンラインサーバーを使う場合は HTTPS 必須

### 質問2：「データが消えた」
**回答：**
- JSON でバックアップしていれば復元可能
- ブラウザのキャッシュをクリアすると消える可能性があります

### 質問3：「オフラインで起動できない」
**回答：**
- 最初は インターネット接続した状態で起動してください
- 2回目以降はオフラインでも起動します

### 質問4：「スマホの容量がいっぱい」
**回答：**
- アプリ本体：約500KB
- データ：カード数に応じて（1,000件で約2-5MB）
- JSON でエクスポートして不要データを削除できます

## 💪 成功のコツ

1. **毎日5-10分で OK**
   - 忘却曲線の科学に基づいた復習間隔
   - 短時間でも継続が最重要

2. **3段階評価を正直に**
   - 😰 忘れた：完全に忘れていたら選択
   - ✓ 理解した：普通に思い出せたら選択
   - 😊 簡単：迷わず答えられたら選択

3. **新しい判例・過去問題を定期的に追加**
   - PC でそれできれいに入力
   - スマホで学習

4. **定期的にバックアップ**
   - 月1回は JSON でエクスポート
   - 大事なデータはクラウドに保存
