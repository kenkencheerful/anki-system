================================================================================
📱 Android + Brave インストール 5ステップガイド
================================================================================

【準備物】
- PC（Windows/Mac/Linux）
- Android スマートフォン
- WiFi ルーター（PC とスマホが同じWiFiに接続可能）
- Brave ブラウザ（未インストール時は Google Play Store から無料インストール）

================================================================================
✅ STEP 1：PC のIPアドレスを確認（2分）
================================================================================

【Windows PowerShell の場合】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Windows キー + R を同時押し
2. 「powershell」と入力
3. Enter キーを押す
4. 以下のコマンドをコピーして右クリック → 貼り付け：

   ipconfig | find "IPv4"

5. Enter キーを押す
6. 画面に出た「IPv4 アドレス . . : 192.168.X.X」の数字をメモ

【得られたIPアドレス例】
  192.168.1.100
  192.168.0.50
  10.0.0.15

【Mac ターミナルの場合】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Spotlight (cmd + Space) で「ターミナル」を検索
2. ターミナルを開く
3. 以下をコピー＆ペースト：

   ifconfig | grep "inet " | grep -v 127.0.0.1

4. Enter キーを押す
5. 「inet 192.168.X.X」の数字をメモ

================================================================================
✅ STEP 2：PC でサーバーを起動（1分）
================================================================================

【PowerShell/ターミナルで実行】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. PowerShell/ターミナルに以下をコピー＆ペースト：

   cd /workspaces/anki-system
   python3 -m http.server 8000

2. Enter キーを押す
3. 以下のように表示されれば OK：

   Serving HTTP on 0.0.0.0 port 8000 ...

⚠️  ここではターミナルを閉じないでください！

================================================================================
✅ STEP 3：WiFi 接続確認（1分）
================================================================================

【PC の WiFi 確認】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Windows：
  1. 右下の WiFi アイコンをクリック
  2. 接続している WiFi 名を確認
  
Mac：
  1. 右上の WiFi アイコンをクリック
  2. 接続している WiFi 名を確認

【Android スマホの WiFi 確認】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Android スマホの「設定」を開く
2. 「ネットワークとインターネット」をタップ
3. 「WiFi」をタップ
4. 接続している WiFi 名を確認

✅ PC と スマホの WiFi 名が同じなら OK！

================================================================================
✅ STEP 4：Brave でアプリを開く（1分）
================================================================================

【URL を入力】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Android スマホで Brave ブラウザを開く
2. URL 入力欄をタップ
3. 以下を入力（自分の IPアドレスに置き換え）：

   http://192.168.1.100:8000

   例：http://192.168.1.100:8000
       http://192.168.0.50:8000

4. 虫眼鏡 🔍 ボタン（検索）をタップ
5. 3-5秒待つ
6. 暗いグラデーション画面に「弁理士試験 暗記アプリ」が表示される

✅ アプリが表示されれば接続成功！

================================================================================
✅ STEP 5：ホーム画面に追加（1分）
================================================================================

【PWA インストール】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Brave でアプリが開いている状態
2. 画面右下の「⋮」（3点）をタップ
3. 「アプリをインストール」をタップ
   ※ 表示がない場合は下にスクロール
4. 確認画面で「インストール」をタップ
5. ✅ 完了！

【ホーム画面の確認】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Android ホーム画面を表示
2. 「弁理士暗記」というアイコン（紫色で「暗」の文字）がある
3. このアイコンをタップ
4. ✅ アプリが全画面で起動！

================================================================================
⚠️  トラブル時の確認項目
================================================================================

【「接続できません」と表示される】
  → PC と スマホが同じ WiFi に接続しているか確認
  → IPアドレスに :8000 が付いているか確認
  → PC のターミナルで Serving HTTP と表示されているか確認

【「アプリをインストール」が表示されない】
  → Brave でページを再読み込み（下にスワイプ）
  → 3-5秒待ってから再度メニュー（⋮）を確認

【「ページが見つかりません」】
  → http:// で始まっているか確認
  → IPアドレスが正しいか確認
  → :8000 が付いているか確認

================================================================================

  → 暗いグラデーション背景

  → ブラウザのアドレスバーが見えない

✅ この2つができたら完全成功です！
