📋 STEP 1：GitHub にリポジトリを作成（3分）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://github.com にアクセス
2. サインイン（アカウントなければ無料作成）
3. 右上「+」→ 「New repository」
4. 入力：
   
   リポジトリ名：anki-system
   公開設定：Public ⭐ 重要！
   
5. 「Create repository」をクリック
6. ✅ リポジトリが作成されます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💻 STEP 2：PC でコマンド実行（5分）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PowerShell（Windows）またはターミナル（Mac/Linux）を開く

コマンドをコピー＆ペースト：

┌────────────────────────────────────────────────────────────────┐
│ git clone https://github.com/yourusername/anki-system.git     │
│ cd anki-system                                                 │
│ cp /workspaces/anki-system/index.html ./                      │
│ cp /workspaces/anki-system/styles.css ./                      │
│ cp /workspaces/anki-system/script.js ./                       │
│ cp /workspaces/anki-system/manifest.json ./                   │
│ cp /workspaces/anki-system/sw.js ./                           │
│ git add .                                                      │
│ git commit -m "Add anki-system files"                         │
│ git push -u origin main                                        │
└────────────────────────────────────────────────────────────────┘

⚠️ 「yourusername」を自分の GitHub ユーザー名に置き換えてください

例：
git clone https://github.com/john-doe/anki-system.git


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔐 GitHub 認証（初回のみ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

「git push」時に以下が表示：

  Username for 'https://github.com': [ユーザー名を入力]
  Password for '...': [Personal Access Token を入力]

【Personal Access Token を取得】

1. https://github.com/settings/tokens にアクセス
2. 「Generate new token」 → 「Generate new token (classic)」
3. Token name：「anki-system」
4. Expiration：「No expiration」
5. Select scopes：「repo」にチェック
6. 「Generate token」をクリック
7. 表示されたトークンをコピー
8. ターミナルで「Password」に貼り付け

✅ Push が完了します


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚙️  STEP 3：GitHub Pages を有効化（2分）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GitHub リポジトリページを開く
   https://github.com/yourusername/anki-system

2. 「Settings」タブをクリック
3. 左メニュー「Pages」をクリック
4. 「Branch」で「main」を選択
5. 「Folder」で「/ (root)」を選択
6. 「Save」をクリック

✅ 以下のようなメッセージが表示：
   「Your site is published at https://yourusername.github.io/anki-system」


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📱 STEP 4：スマホでアクセス（2分）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

スマホで Brave または Chrome を開く

URL 入力欄に以下を入力：
  https://yourusername.github.io/anki-system

例：
  https://john-doe.github.io/anki-system

✅ アプリが表示されます！

📌 STEP 5：ホーム画面に追加（1分）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Android の場合】
1. Brave でアプリが開いている
2. 画面右下の「⋮」をタップ
3. 「アプリをインストール」をタップ
4. 「インストール」をタップ
5. ✅ ホーム画面に「弁理士暗記」が追加

【iPhone の場合】
1. Safari でアプリが開いている
2. 下部の「共有」をタップ
3. 「ホーム画面に追加」をタップ
4. ✅ ホーム画面に「弁理士暗記」が追加

Q1. Personal Access Token とは？
A.  GitHub へのアクセス認証用。パスワード代わりに使用。

Q2. 反映されるまでどのくらいかかる？
A.  通常 1-2分。初回は最大 5分程度。

Q3. ファイルを更新したい場合は？
A.  git push するだけで自動反映。

Q4. オフラインで使える？
A.  はい。2回目以降はインターネット不要。

Q5. 他の人と共有できる？
A.  URL を教えればだれでもアクセス可能。

Q6. データは安全？
A.  LocalStorage に保存。HTTPS で保護。
